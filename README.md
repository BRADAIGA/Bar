# Тёплый угол

Игра про работу в баре. Здесь публикуются сборки и описание обновлений.

## Скачать

Откройте [последний релиз](https://github.com/BRADAIGA/Bar/releases/latest) и скачайте **WarmCorner-Launcher.zip**. Распакуйте архив, запустите WarmCornerLauncher.exe и нажмите «Установить». Лаунчер создаёт папку WarmCorner в выбранном месте и проверяет опубликованные обновления.

Архив **WarmCorner-Windows.zip** позволяет запустить игру напрямую.

## Совместная игра

Windows x64, до четырёх игроков через локальную сеть или Radmin VPN. Все участники должны использовать одинаковую версию. Хозяин создаёт комнату, остальные подключаются по его IP и порту 7777. Хозяин остаётся в игре до конца смены.

Текущий выпуск предназначен для проверки: совместная игра на разных компьютерах ещё тестируется.
